# 🐟 Sayda: Smart Underwater Fish Trap

نظام ذكي ومبتكر لصيد الأسماك تحت الماء، يدمج بين الرؤية الحاسوبية (Computer Vision) والتحكم الآلي لاكتشاف واصطياد أنواع محددة من الأسماك بشكل مستقل.

## 🎯 فكرة المشروع
يهدف مشروع "صيدة" إلى أتمتة عملية الصيد باستخدام تقنيات الذكاء الاصطناعي. يقوم النظام بالتعرف على الأسماك المستهدفة في الوقت الفعلي (Real-time) وإغلاق المصيدة آلياً بناءً على قرار الخوارزمية، مما يقلل من الصيد الجائر للأنواع غير المستهدفة.

## 🛠️ التقنيات والمكونات المستخدمة
* **الذكاء الاصطناعي:** نموذج `YOLOv8` المخصص لاكتشاف الكائنات، ومكتبة `OpenCV` لمعالجة الصور.
* **المعالج المركزي:** Raspberry Pi (للمعالجة والتحكم).
* **نظام الرؤية:** كاميرا ESP32-CAM / USB Endoscope Camera (مقاومة للماء).
* **المحركات (Actuators):** 4 محركات سيرفو DS3235 (IP67 Waterproof).
* **التحكم الحركي:** لوحة PCA9685 (عبر بروتوكول I2C).
* **لغة البرمجة:** Python & Arduino (C++).

## 📂 هيكلية المشروع
* `sayda_servo.py`: الملف الرئيسي لتشغيل النظام بالكامل (الكاميرا، نموذج الذكاء الاصطناعي YOLOv8، والتحكم في السيرفو).
* `arduino_servo_test.ino`: جسر تواصل لاختبار حركة السيرفو عبر الويندوز أثناء مرحلة التطوير.
* `requirements.txt`: يحتوي على جميع المكتبات اللازمة لتشغيل البيئة.

## 🚀 كيفية التشغيل
1. قم باستنساخ المستودع (Clone).
2. قم بتثبيت المتطلبات عبر الأمر:
   `pip install -r requirements.txt`
3. قم بتشغيل الملف الرئيسي للرؤية الحاسوبية لاختبار الكاميرا والنموذج.
